# 🌐 Alvine's Portfolio

Welcome to my personal portfolio website — built with **React** and hosted on **GitHub Pages**.  
It showcases my projects, skills, and background as an aspiring IT Support Specialist and future cybersecurity pro.  

## 🚀 Live Demo
🔗 **[View Portfolio](https://alvine-chungo969.github.io/alvine-portfolio/)**

## 📌 Features
- Responsive design (works on mobile, tablet, and desktop)
- Showcases my **projects, skills, and contact details**
- Built with **React** and deployed using **gh-pages**
- Easy to update and maintain

## 🛠️ Technologies Used
- **React.js** (Create React App)
- **HTML5**, **CSS3**, **JavaScript (ES6+)**
- **Git** & **GitHub Pages**
- **npm** for package management

```bash
